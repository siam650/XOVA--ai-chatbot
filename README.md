# Xova — Speak Freely. Grow Naturally.

Xova is an AI-powered English-speaking practice platform that I'm building to help people improve their English through natural conversations.

I'm building this project for two reasons: to improve my own English communication skills and to learn web development by creating something useful.

### Planned Features
- AI-powered English conversations
- Grammar corrections and feedback
- Natural expression suggestions
- Different conversation modes
- Voice-based practice
- Learning progress tracking

### Tech Stack
- HTML
- CSS
- JavaScript

### Current Status
Currently working on the frontend. AI integration and other features are planned for future development.

**This is a work in progress.**
